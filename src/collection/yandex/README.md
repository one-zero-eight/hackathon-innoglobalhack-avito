# Яндекс Исполнители

Для запуска нужны Python 3.11+ и curl. Скрипт читает описания профилей из публичных страниц каталога.
Он сохраняет ID исполнителя, ссылку на каталог и описание. Телефоны и email
маскируются. При повторном запуске совпадающие ID и тексты пропускаются.
Каталог указывает источник выборки. Проверенная метка микрокатегории
в выгрузку не входит.

```sh
python3 src/collection/yandex/collect.py \
  --pages 2 --min-length 300 \
  https://uslugi.yandex.ru/43-kazan/category/remont-i-stroitelstvo--1344
```

Результат по умолчанию сохраняется в `out/yandex/profiles.jsonl`.

Без ссылок скрипт перебирает каталоги 16 крупных городов, включая Москву,
Санкт-Петербург, Казань, Екатеринбург и Новосибирск. В списке есть общий ремонт, ремонт квартир и домов,
электромонтаж и сантехнические работы. Свои ссылки можно передать
позиционными аргументами.

```sh
bash src/collection/yandex/run.sh 500
```

Скрипт продолжает сбор до заданного числа записей или исчерпания каталогов.
Порог по умолчанию — 300 символов. Описания любой длины сохраняются
в `out/yandex/profiles.cache.jsonl`, а номера следующих страниц — в
`out/yandex/profiles.pages.json`. Повторный запуск продолжает сбор с
сохранённой страницы. Для повторного обхода уже обработанных каталогов
можно удалить файл с номерами страниц. Запускайте один процесс на файл.

На Linux команда `bash src/collection/yandex/run-workers.sh 500` обрабатывает
до четырёх городов одновременно. После числа можно указать коды городов. Нужна утилита `flock`. Журналы и кэш каждого
процесса находятся в `out/yandex/workers/`. После каждой партии скрипт
объединяет записи по ID исполнителя и нормализованному описанию в
`out/yandex/profiles.jsonl`.
