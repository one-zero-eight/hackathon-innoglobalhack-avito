# Бенчмарк dataset_annotation: время и примеры

Никакого F1: здесь проверяется только применение **уже сохранённых**
train-review решений к 3196 строкам из `out/rubert-thresholds/train.jsonl`.
Исходный SHA-256 `e8cd0f21260b43dadbda3edd60c97720fe045d810c3252ff8950aad6fb3e5186`.
Файл `decisions.json` содержит 64 предварительных решения ассистента,
**не независимую ручную разметку**. Изменений меток в нём 0; веса 35
подтверждённых трудных примеров повышены до 1.5.

## Запуск

```bash
uv run python src/dataset_annotation/rubert_review/benchmark.py
```

Отчёт: `results.json`. Никаких новых папок, API-запросов, обучения
или изменения датасета. Если локальный train отсутствует или не совпадает
с исходным, benchmark явно завершается ошибкой.

## Время

Фактический вызов `load_reviewed_rows()` на 3196 записях:
**0.056805 с** (один вызов; около 0.018 мс на строку).
Измерено `perf_counter()`; чтение файла и JSON-сериализация отчёта
не включены. Это время применения review, **не** время создания
первичных меток человеком или языковой моделью.
