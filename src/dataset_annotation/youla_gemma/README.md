# Разметка Юлы Gemma

```bash
PYTHONPATH=src uv run python -m dataset_annotation.youla_gemma.annotate --limit 10
```

Источник по умолчанию: `docs/provider_collections/youla-1469-raw.jsonl`.
`--source` меняет вход, `--output` — каталог кэша (по умолчанию
`out/youla-gemma-4-26b`). Ключ: `GOOGLE_API_KEY`, `GEMINI_API_KEY` или
`LLM_API_KEY` из окружения / `.env`. Модель исходного инструмента —
`gemma-4-26b-a4b-it`; её доступность новым API-прогоном не проверялась.

Очередь фиксируется seed=43, до 1000 строк. Для исключения контрольной
выборки явно передайте `--exclude-rows <labels.jsonl>` с полем `row`.
Скрытой зависимости от локального backlog нет. При изменении источника,
очереди или промпта используйте новый каталог кэша.

SQLite сохраняет каждую попытку и проверенные метки, `manifest.json` —
промпт, модель, хеш входа и очередь; `labels.jsonl` выгружается при завершении
и остановке. Повторный запуск продолжает очередь. Ограничитель учитывает
попытки, повторы и оценку токенов; фактический usage остаётся в ответах.
Это инструмент разметки, F1 здесь не считается. При переносе API не вызывался.
