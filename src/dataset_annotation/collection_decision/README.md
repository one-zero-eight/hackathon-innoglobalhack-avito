# Разметка внешних коллекций Google Decision

```bash
PYTHONPATH=src uv run python -m dataset_annotation.collection_decision.annotate --inputs out/youla-1469.jsonl out/yandex/profiles-1492.jsonl --limit 10
```

Пути передаются через `--inputs`; по умолчанию используются указанные выше
выгрузки сборщиков. Соседние файлы `*-decision-1.jsonl` содержат исходную
запись, конфигурацию, вероятности и проверенные метки всех шести категорий.
Повторный запуск проверяет сохранённый префикс и продолжает разметку.
Клиент, промпт и настройки переиспользуются из `google_decision`, его код
не изменяется. Ключи и параметры — через `.env`. Кэш блокировки — в `out/`.

Сохранённые снимки PR #9: `docs/provider_collections/`. Повторные API-запросы
при переносе не выполнялись. Это разметка данных, F1 здесь не считается.
Запуск с путями внутри docs дописывает результаты рядом с ними; для нового
эксперимента сначала скопируйте исходники в out, чтобы сохранить снимки.
