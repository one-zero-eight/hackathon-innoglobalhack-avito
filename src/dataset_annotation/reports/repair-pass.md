# Повторный проход разметки

Дата: 2026-11-14. Ветка: `ARCshekin/feat/improved_dataset`.

## Метод и границы

Главный агент исправил общие правила и повторно вычислил метки **всех
4993 уникальных групп** из 10208 исходных строк. Субагенты в этом проходе
не использовались. Это не ручное прочтение каждого описания и не оценка F1.

1111 непроверенных решений шардов исключены из активных правил; они и
предыдущие решения сохранены в `docs/improved_dataset/review_history/`.
24 индивидуальных ответа пользователя сохранены без изменений.
`repair_changes.jsonl` фиксирует 609 изменённых групп относительно
предварительного набора до исправлений.

## Исправления

- Распознаются «Возможно, вы искали», «Для поиска» и другие SEO-маркеры,
  в том числе после текста в той же строке. SEO не влияет на контекст
  соседних упоминаний услуг.
- «Утепление пола» не считается сантехникой; тёплый пол различается
  по указанному типу, при отсутствии типа учитываются оба варианта.
- Произвольное нечёткое сопоставление слов заменено явным списком опечаток.
- Отказы до и после упоминания частичного ремонта обрабатываются отдельно
  от положительного предложения частичных работ.
- Упоминание полного завершения ремонта не отменяет отказ от частичных работ.
- Покраска труб и радиаторов не является их сантехническим монтажом.
- Затирка межплиточных швов относится к плиточным работам.
- Объект «без отделки» не считается обещанием отделочных услуг.

## Измеренный результат

| Показатель | Значение |
| --- | ---: |
| Исходных строк | 10208 |
| Уникальных групп | 4993 |
| Train после дедупликации и исключения шума | 4851 |
| Диагностический test без известных пересечений | 119 |
| Изменены метки относительно предварительного набора | 609 |
| Групп с диагностическими отметками | 1574 |

Число отметок увеличилось относительно промежуточных 429, поскольку
непроверенные ответы шардов больше не снимают сомнения автоматически.
Это не доля доказанных ошибок: сюда входят слабые лексические сигналы,
общие формулировки без названных услуг и другие причины.
Набор не объявляется вручную подтверждённым эталоном.
