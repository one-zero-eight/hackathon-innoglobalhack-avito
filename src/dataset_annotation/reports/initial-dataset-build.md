# Проверки сборки производного improved_dataset (история)

Сервис: dataset_annotation  
Дата: 2026-11-14   Автор: ARCshekin

Историческая служебная проверка сборки. Она не описывает результаты новой политики полной разметки и не является оценкой реализаций классификатора.

## Что проверяем и почему

Проверяем воспроизводимость очистки и учёт исходных строк, а не качество
классификатора. Оригиналы не изменяются, спорные метки не угадываются:
неразрешённые случаи исключаются из рабочего поднабора в карантин.

```json
{
  "train": "docs/innoglobalhack_avito/public-train-annotated.jsonl",
  "test": "docs/innoglobalhack_avito/public-test-dataset.parquet",
  "decisions": "docs/improved_dataset/decisions.json",
  "output": "docs/improved_dataset",
  "normalization": "NFKC, casefold, ё→е, whitespace",
  "known_near_overlap_threshold": 0.92,
  "classification_evaluation": false
}
```

Запуск:

```sh
PYTHONPATH=src uv run python -m dataset_annotation.audit_dataset
PYTHONPATH=src uv run python -m dataset_annotation.build_improved_dataset
```

После последующих ответов в CLI актуальные счётчики следует смотреть в
`docs/improved_dataset/manifest.json` и README; таблица выше фиксирует
состояние именно после первых четырёх ответов в чате.

### Проверяемые инварианты

- Хеши исходных JSONL/parquet совпадают с зафиксированными в decisions.
- Исходные тексты, заголовки и схемы сохранены в выходных записях.
- Учтены все 10208 исходных строк без повторов идентификатора `(split, row)`.
- В каждой выходной части нет нормализованных дубликатов.
- Нормализованные дубликаты после исправлений имеют один набор меток.
- Из диагностического test удалены известные точные и близкие пересечения
  с исходным train, включая его карантин.
- Карантин и исключения сохраняют полный исходный JSON и причину.
- Каждая правка меток имеет решение и журнал до/после.
- Повторная сборка в одном окружении воспроизводит байты всех девяти файлов.

## Выводы

Получен консервативный производный набор с отслеживаемыми правками.
Карантин не равен списку ошибочных меток: фильтры могут исключать корректные
примеры и меняют распределение данных. Очищенный набор не является полностью
вручную проверенным эталоном. `reviewed_test.parquet` — просмотренный
диагностический поднабор, не независимый финальный holdout.

Пайплайны, config.json и пути обучения по умолчанию не переключались.
