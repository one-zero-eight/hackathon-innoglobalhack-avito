# Время ответа выделения категорий

Сервис: subcategory_extraction.

## Что проверяем

Настоящий `run()` модулей `tfidf` и `google_decision` на одних 10 входах.
Источник — validation-группы официального train из разбиения
[TF-IDF](../tfidf_quality/README.md); seed выборки 44.
Прогон выполнен после завершения [сравнения промптов](../prompt_comparison/README.md),
без параллельных запросов к Google Decision от этого задания.
Google использует рабочий guided и порог 0.5.

Таймер оборачивает `run()` после создания экземпляра; загрузка модели,
чтение выборки и запись отчёта не входят. Прогрева нет. Ожидание токенного
бюджета и сетевые повторы, если они возникнут, входят во время ответа.
Среда локального запуска: macOS 27.0.1, arm64, Python 3.13.15.

## Запуск

```bash
uv run python src/subcategory_extraction/benchmarks/tfidf_quality/run.py
uv run python src/subcategory_extraction/benchmarks/response_time/run.py
```

`--module tfidf` и `--module google_decision` выбирают один модуль;
`--size` меняет размер выборки, `--report` — путь отчёта.
Первый запуск создаёт веса. Для Google нужен ключ в `.env`.
[Полный отчёт](results.json) содержит group_id, предсказания и время каждого вызова.
