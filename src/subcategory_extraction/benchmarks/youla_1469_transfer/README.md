# Бенчмарк: перенос Youla → InnoGlobalHack

Сервис: `subcategory_extraction`.

## Что проверяем

Обучаем пять вариантов и проверяем 12 смесей логитов из `run_youla_keywords.py` на разметке Gemini Decision 1 для 1 469 объявлений Youla ([снимок разметки](../data/youla-1469-decision-1.jsonl), SHA-256 `129b7491bdd2441070fba20a37c82e074ba56589239b65146702805d1b8758d8`). Одна строка с ошибкой `prohibited_content` исключена: обучение на 1 468 объявлениях. Метки 101 исключаются из целевых категорий. Это эксперимент переноса с внешним обучающим корпусом, не оценка качества ручной разметки Youla.

Измерения: оригинальная автоматическая разметка `docs/innoglobalhack_avito/public-train-annotated.jsonl`, группировка похожих описаний, seeds 44/45, validation для выбора порогов, независимый holdout для micro-F1. Официальный public-test не используется. Прямых совпадений с обучением на holdout: 0. Источник категории в организаторском наборе — 101. Основной показатель — micro-F1 на holdout после выбора метода и пяти порогов по validation micro-F1 (сетка 0.00–1.00, шаг 0.01). Фиксированный порог 0.50 оставлен как baseline. Смешиваем пары logits с весами 0.25, 0.50 и 0.75; смеси, веса и пороги выбираются без доступа к holdout. Данные Youla размечены моделью, поэтому числа не доказывают качество на независимой ручной разметке.

## Запуск

Из корня репозитория после завершения разметки:

```bash
PYTHONPATH=src uv run python src/subcategory_extraction/benchmarks/youla_1469_transfer/run.py
```

Отчёт: [results.json](results.json). Скрипт проверяет число строк, уникальность URL, конфигурацию и метки, не меняет исходный файл и сохраняет отчёт только после успешного прогона. Время включает обучение, оценку и проверку inference-модуля, **не** является временем ответа одной модели. Цена локального запуска — бесплатно; цена API-разметки здесь не измерялась.

## Выводы

При фиксированном пороге лучший micro-F1 — 0.9167 (combined). Среди одиночных методов и смесей **только по validation** выиграли keywords (0.9285), с порогами 102–106: 0.25, 0.43, 0.10, 0.21, 0.41 (точные значения — в отчёте); на holdout — **0.9181**. Лучшая смесь проиграла на validation и на holdout. Выбор смеси по holdout был бы утечкой; не переносим результаты на официальный public-test без отдельной проверки.
