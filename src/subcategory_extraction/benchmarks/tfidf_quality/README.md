# Качество TF-IDF

Сервис: subcategory_extraction.

## Что проверяем

Заново обучаем TF-IDF + логистическую регрессию на официальном
`docs/innoglobalhack_avito/public-train-annotated.jsonl`.
SHA-256 датасета: `b7118d68086624fbeab43839f22a635d4e325e4ee339f22d4aa0ad3c2e986615`.
Точные нормализованные дубликаты объединяются до разбиения:
NFKC, casefold, ё→е, схлопывание пробелов. Близкие шаблоны отдельно не группируются.

4 854 уникальных описания: train 3 397, validation 728, holdout 729.
Первое разбиение: 70/30, seed 42; оставшиеся группы делятся пополам, seed 43.
Порог выбирается только на validation из 0.3/0.4/0.5/0.6/0.7.
В этом прогоне выбран **0.5**.
Векторизатор и классификаторы обучаются только на train.
JSON-артефакт проверяется через настоящий `load_pipeline()` на всех 729 holdout-входах.

## Запуск

```bash
uv run python src/subcategory_extraction/benchmarks/tfidf_quality/run.py
```

Веса: `out/tfidf.json`; [полный отчёт](results.json) содержит группы всех частей.
`--dataset`, `--artifact`, `--report` позволяют явно задать другие пути.
