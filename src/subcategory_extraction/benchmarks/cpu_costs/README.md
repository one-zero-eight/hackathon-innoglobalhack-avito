## Обновление

Одна строка на решение; повторный замер заменяет эту строку. Дату,
версию, объём и тариф обновляем вместе. Отдельные таблицы по прогонам,
авторам и PR не создаём. Исходные usage:
[recorded-results.json](../classifier_methods/recorded-results.json).
Метрики качества и времени находятся в собственных сценариях, а не
дублируются здесь. При проверке сохранённых ответов новых расходов нет;
это не обнуляет стоимость получения исходных ответов.

Прямой тариф TypeSafe не подставляется вместо тарифа BestAPI.
Внешние API при переоформлении не вызывались. История заменённых
результатов доступна в Git; исходные recorded-results.json не изменяются.

Проверки CLI с генератором sample_llm относятся к полной цепочке,
а не к стоимости классификатора. Ранее для них сохранены 446 input +
135 output и 390 input + 100 output токенов gemini-3.5-flash-lite;
тариф неизвестен. Они не складываются с этой таблицей.
