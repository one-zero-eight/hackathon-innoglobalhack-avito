# Бенчмарк: стоимость токенов
Сервис: subcategory_extraction

## Что проверяем

Стоимость внешних вызовов на фактически использованном объёме токенов.
Цена заполняется **вручную** человеком/агентом по подтверждённому тарифу
провайдера и usage. Неизвестный тариф нельзя считать нулём.
Локальные классификаторы и офлайн-пересчёт: бесплатно в смысле API-платежей;
электричество и оборудование не включены.

## Как обновлять

Скрипта стоимости нет. После F1/временного прогона вручную впишите
объём input/output токенов, фактический тариф/квоту, дату и сумму.
Исходный usage сохранён в `../classifier_methods/recorded-results.json`.
