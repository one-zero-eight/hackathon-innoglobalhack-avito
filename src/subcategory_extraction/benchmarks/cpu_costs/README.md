# Бенчмарк: стоимость токенов
Сервис: subcategory_extraction

## Что проверяем

Стоимость внешних вызовов на фактически использованном объёме токенов.
Цена заполняется **вручную** человеком/агентом по подтверждённому тарифу
провайдера и usage. Неизвестный тариф нельзя считать нулём.
Локальные классификаторы и офлайн-пересчёт: бесплатно в смысле API-платежей;
электричество и оборудование не включены.

## Как обновлять

Скрипта стоимости нет. После F1/временного прогона вручную впишите
объём input/output токенов, фактический тариф/квоту, дату и сумму.
Исходный usage сохранён в `../classifier_methods/recorded-results.json`.

## Selectel Jev: 2026-11-14

Модель `typesafe/jev-1.13`, endpoint `https://api.selectel.ru/aig/v1/decisions`.
Цена внесена вручную по `usage.cost` успешных ответов, не сверка счёта.
Selectel тарифицирует ИИ-роутер в рублях; модели имеют динамические цены:
[официальная модель оплаты](https://promo.selectel.ru/ai-router).
Метаданные API models на момент проверки: prompt 0.000005548 RUB/токен,
completion 0; актуальная панель и биллинг имеют приоритет.

| Задержка, 10 run(), без чтений кэша | 10 | 30 916 / 990 | 0.171522 RUB |

Пользователь разрешил завершение с бюджетом до 5 RUB. После этого оба F1-сценария

Проверка схем и CLI с сохранённым Selectel-ответом и подменой генератора
не обращалась к API. Для сетевых попыток без ответа полный расход неизвестен;
ответы с gateway.cached и стоимостью 0 не заменяются вымышленным тарифом.
Сами ответы хранятся в локальном out/jev-cache и out/selectel-latency-cache,

## Jev: train-оптимизация

Пользователь отдельно разрешил передачу 72 групп официального public train
Selectel:48 fitting +24 control для двух промптов. Модель закреплена:
`typesafe/jev-1.13`. 144 успешных ответа; их суммарный reported usage.cost —
1.534188440 RUB. Вместе с прежним переключением провайдера 2.353228584 RUB
это 3.887417024 RUB подтверждённых успешных ответов.

Из-за сетевых сбоев дополнительно зарезервировано 0.909677820 RUB как
консервативная верхняя оценка неподтверждённых попыток; это не заявляется
фактическим списанием. DNS/IPv4 и persistent TLS-connection использовались
только для устойчивого сбора; HTTPS hostname и проверка сертификатов сохранены.
Последний train-проход полностью воспроизведён из текущего Jev-кэша, бесплатно
по новым вызовам. Перебор порогов не генерировал дополнительных запросов.

Отчёт обучения: `../classifier_methods/jev-training-results.json`.
Реальный счет проверяется в Selectel; отдельный pricing runner не добавлялся.
