# Бенчмарк: итоговая классификация без генерации текстов

Сервис: subcategory_extraction.

## Что проверяем

Текущий extractor с неизменёнными guided и порогом 0.5 на официальном
`public-test-dataset.parquet`, 208 строк. Названия меток проверяются через
общую таблицу; перед оценкой проверяется пересечение с официальным train.
Прогнозы оформляются как drafts с null-текстами исключительно для измерения
классификации. Это не результат полного пайплайна с генерацией.

## Запуск

```bash
uv run python src/subcategory_extraction/benchmarks/final_classification/run.py
```

`--config`, `--report`, `--resume` задают конфигурацию и контрольную точку.
Resume разрешён только при совпадении отпечатка кода, данных и настроек.
Время включает run(), повторы API и ожидания квоты; загрузка экземпляра и
данных не включается. Стоимость неизвестна: тариф аккаунта не уточнён.

## Последний прогон

Прогон прерван по просьбе пользователя при переключении на задачу HTTP API.
Завершены 78/208 строк; статус failed, итогового F1 нет. Частичные ответы
сохранены в [results.json](results.json), вместе с датой, commit, хешем кода,
хешем датасета и настройками. Модель и промпт на test не подбирались.

проверку resume; в таком случае требуется отдельный новый прогон.
