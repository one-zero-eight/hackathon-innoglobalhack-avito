## Запуск

```bash
OMP_NUM_THREADS=1 OPENBLAS_NUM_THREADS=1 TFIDF_ARTIFACT_PATH=out/classifier-methods/tfidf.json uv run python src/subcategory_extraction/benchmarks/improved_dataset/run.py --methods regex tfidf learned_keywords --offline
```

Для других реализаций замените список `--methods`. Для проверки исходного
снимка ответов используйте `--replay`; это пересчёт старых предсказаний,
а не измерение текущих весов или задержки модели. Флаг `--offline` запрещает
API-модули. Отсутствие весов/API фиксируется как ошибка без F1.
После запуска обновите соответствующие строки этой таблицы по JSON.

## Условия и ограничения

- У TF-IDF фиксированные веса SHA-256
  `2ef7ed22c74a13820b1b06d53b5a84d6c8555b082f4bcab5b6e0408164acf62b`.
  Фактический train: `out/classifier-methods/hybrid-training.jsonl`, 4821 строка
  исходного train после фильтрации; SHA-256
  `c1443632946d88618d2d9cd925258374e87152ab44b2fb45d628923242e4971b`.
- learned_keywords обучен на исправленном train: 4851 строка,
  combined-признаки, 40 фраз на категорию, C=4, порог 0.5.
  semantic_encoder_f1 использует опубликованные фиксированные веса и калибровку.
  Переобучения или подбора порогов по test при этих измерениях не было.
- Regex — адаптер неизменённой `annotate_dataset.propose()`, без индивидуальных
  исключений и сохранённых ответов. Правила дорабатывались с использованием
  test, а исправленные метки в основном созданы этими же правилами.
  Его высокий F1 на исправленном наборе не доказывает обобщения.
- Исправленный test — диагностический, с предварительной автоматической
  разметкой; исходный test содержит дубликаты и спорные метки.
  Строки из оценки не исключаются. Два датасета не объединяются в одну метрику.
- Точные нормализованные пересечения с фактическим train: TF-IDF **0/119**;
  learned_keywords и semantic_encoder_f1 **0/119**.
  Это не полный поиск близких/семантических дубликатов. У моделей разные train.
- Даты, отпечатки кода, веса и условия измерения каждой строки сохранены в JSON.
  Результаты других решений при переоформлении не пересчитывались.
  Заменённые версии доступны в истории Git, отдельных таблиц прогонов нет.
