# Разметка Youla с Gemma 4 26B

Из корня проекта запустите:

```sh
PYTHONPATH=src uv run python src/subcategory_extraction/annotation/youla_gemma.py
```

Ключ берётся из окружения или `.env`. Поддерживаются `GOOGLE_API_KEY`, `GEMINI_API_KEY`
и `LLM_API_KEY` в порядке приоритета. Для короткого прогона укажите `--limit 10`.
Повторный запуск продолжает ту же выборку из 1 000 строк. Слепая контрольная
выборка из 100 объявлений исключена. В Google отправляются только описания,
по одному на запрос.

В `out/youla-gemma-4-26b/` сохраняются:

- `manifest.json` с промптом, моделью, хешем источника и очередью строк.
- `cache.sqlite3` с запросами, ответами, метаданными расхода от Google и метками.
  Ключ в базу не записывается. Успешные метки сохраняются после каждого запроса.
- `labels.jsonl` с исходными строками и проверенными метками. Выгрузка обновляется
  при остановке программы. База остаётся источником данных при аварийном завершении.

Локальный ограничитель учитывает до 30 запросов и 16 000 оценочных токенов за
скользящее окно в 61 секунду и до 14 400 запросов за 24 часа. Для оценки берётся
размер тела запроса в UTF-8 с запасом. Общий расход проекта контролирует Google.
После повторных ошибок квоты программа сохраняет кэш и останавливается.
