# Полный смысловой арбитраж

Один заранее зафиксированный system prompt следует тем же общим границам категорий,
что jev_semantic. Модель проверяет все eligible-категории, включая отрицательные prior,
по полному тексту. Native вероятности — вспомогательные данные, не готовые ответы.
Отсутствуют сопоставления по ID/хешам и строки из конкретных private-объявлений.
Выход — строгая схема бинарных решений, один ответ на каждую категорию.
