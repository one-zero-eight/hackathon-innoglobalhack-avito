# Логрег формата заказа

Бинарная логистическая регрессия определяет, принимает ли исполнитель
только комплексные заказы. По всему объявлению выделяются окна в 11 слов
вокруг слов формата заказа. Используются те же признаки, что в логреге
категорий: бинарные словесные и символьные n-граммы и пары «якорь + фраза».
Словарь и веса обучаются на размеченных объявлениях. Порог — 0,5.

Для подключения укажите `"subcategory_extraction":
"lexical.order_format_logistic_regression"` в `config.json`. Сначала
работает исходный snippet-логрег категорий. При обнаруженном общем отказе
его результат очищается. Отдельно детектор можно вызвать через
`OrderFormatClassifier().refusal_probability(description)`.

## Воспроизведение

```bash
PYTHONPATH=src uv run python -m subcategory_extraction.lexical.order_format_logistic_regression.train \
  out/order-format/ads-100.jsonl --report out/order-format/logreg-results.json
```

Отчёт содержит прогнозы на отложенных фолдах и ошибки по каждому
объявлению. Для Avito используются пять стратифицированных фолдов,
похожие описания остаются в одном фолде. Два объявления Юлы
прогнозируются отдельно и исключены из обучения. Для каждого фолда
словарь и коэффициенты обучаются заново. Итоговые веса в
`artifacts/model.json.gz` обучены на всех 98 объявлениях Avito.

При пороге 0,5 на 100 объявлениях детектор обнаружил 42 из 50 отказов
и ошибочно сработал на 9 из 50 контрольных. В контроле без явного
предложения отдельного заказа — 8 из 38, с таким предложением — 1 из 12.
Это проверка бинарного детектора на целевой выборке, а оценка полноты
категорий требует отдельной разметки.
