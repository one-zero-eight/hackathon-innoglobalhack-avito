# Фразовый логрег формата заказа

Оценивает предложения и строки объявления по словесным и символьным
n-граммам. Все фрагменты проходят классификатор. Классы — общий отказ,
отказ по услуге, разрешение отдельного заказа и нейтральный фрагмент.
Решение привязано к дословной цитате. Общий отказ снимает все найденные
категории, адресное ограничение применяется к упомянутым категориям,
а разрешение возвращает соответствующие категории. Для определения
упомянутой категории используются короткие списки словоформ.

Модуль выбирается через `"subcategory_extraction":
"lexical.order_format_phrase_logreg"` в `config.json`. По умолчанию он
не включён. Три размеченных примера отказа по услуге пока дают слишком
мало данных, чтобы надёжно отделять его от общего отказа.

## Воспроизведение

```bash
PYTHONPATH=src uv run python -m subcategory_extraction.lexical.order_format_phrase_logreg.train out/order-format
```

В локальном каталоге нужны исходные `ads-100.jsonl` и
`logreg-results.json`, ручная разметка `phrase-labels.json` и два
написанных для проверки набора `phrase-control.jsonl` и
`phrase-blind.jsonl`. Веса исходного логрега нужны для сравнения.
Порог 0,5 фиксирован. Разбиение исходной сотни повторяет фолды
документного логрега. Дополнительно проверяются группы близких описаний
с учётом отдельно размеченного объявления. Два объявления Юлы
в обучение не входят. Вес автоматически добавленного фонового текста
ограничен на уровне объявления. Оба написанных контрольных набора
используются только для оценки.

`phrase-results.json` содержит результаты на уровне объявления и
проверочных категорий, включая цитаты с оценкой. На исходной сотне
число объявлений с ошибочным снятием уменьшилось с 9 до 4, а число
пропущенных снятий выросло с 8 до 14. Точных наборов категорий —
82 вместо 83. На 24 написанных контрольных примерах точных наборов
12 вместо 15, на 12 новых — 6 вместо 4. Примеров недостаточно, чтобы
подтвердить улучшение на новых естественных объявлениях.
