# Проверка действия и области заказа

Вариант `lexical.order_format_scope` использует готовые категории
snippet-логрега. Для их фильтрации правила связывают признак ограничения
с объектом заказа в той же фразе. «Только комплексные проекты» задаёт
общее ограничение. «Плитку отдельно не кладём» связывает запрет с
плиточными работами. Общее разрешение принимать отдельные этапы
сосуществует с адресным запретом. Отдельно сохранена возможность
проверить тот же анализ только на фразах, предложенных фразовым логрегом.

Связь с категорией определяется упоминаниями в части предложения.
Сложные перечисления без разделителей и косвенные ограничения остаются
трудными. Определение наличия услуг по-прежнему выполняет исходный логрег.
По умолчанию новый вариант не включён.

Проверки фильтра выполнены с фиксированными входными категориями.
В `out/order-format/scope-results.json` записаны результаты по исходной
сотне, двум прежним контролям, объявлениям Terra и двум новым написанным
контролям. Материалы Terra и старые контрпримеры использовались при
разборе ошибок. Сравнение на них — проверка регрессий. Новые контроли
содержат 14 и 8 примеров и были записаны до соответствующих прогонов.
Первый из этих контролей использовался при следующей итерации.
