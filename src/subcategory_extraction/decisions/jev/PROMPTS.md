# Сравнение промптов облачного Jev

Автор модуля: Lev Vizan; транспорт Selectel: ZolotarevAlexandr.

| Вариант | Файл | Отличие |
| --- | --- | --- |
| baseline | `prompts/baseline.md` | Короткий независимый вопрос о категории |
| guided | `prompts/guided.md` | Вопрос, примеры работ и ограничения на домысливание услуг |

По умолчанию используется локальный guided; `JEV_PROMPT_PATH` позволяет выбрать
baseline или внешний шаблон. Каждый вопрос форматируется через `{category}` и
`{examples}`. Jev возвращает Noul-вероятности, затем применяется порог.
Файлы перенесены побайтно из прежних Google-шаблонов: это сохраняет поведение,
но теперь модуль владеет собственными промптами. Результаты Google нельзя
приписывать Jev: сравнение проводят отдельно в общих бенчмарках.
