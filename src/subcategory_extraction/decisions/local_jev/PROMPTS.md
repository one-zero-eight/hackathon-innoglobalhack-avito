# Сравнение промптов локального Jev

Автор: ZolotarevAlexandr.

| Вариант | Файлы | Отличие |
| --- | --- | --- |
| english | `prompts/english.md`, `prompts/english-examples.json` | Английская инструкция и английские примеры для категорий |
| guided_ru | `prompts/guided_ru.md` | Русский guided с общими примерами работ |

Выбор: `LOCAL_JEV_PROMPT=english|guided_ru`, по умолчанию english.
`LOCAL_JEV_PROMPT_PATH` переопределяет текст; язык примеров задаётся вариантом.
Английский шаблон обрезается strip(), русский читается без изменения.
Русский файл скопирован побайтно из прежнего общего шаблона Google.
Язык влияет на работу upstream jevos-v5; результаты облачного Jev к нему
не переносятся. Сохранённый guided_ru-прогон имел F1=0; это историческое
измерение, а не результат переноса. Подробности — в README модуля и бенчмарках.
