## Описание и история первого checkpoint


Сервис: draft_generation; дополнительно проверяется общий транспорт Google Decision.

## Что проверяем

Один офлайн-сценарий для `APIClientSettings`, `JSONTransport`,
`GoogleDecisionClient`, `GoogleGenerationClient` и `OpenAICompatibleClient`.
Транспорт подменён; API-ключ — заведомо нерабочий placeholder.
Настоящих вызовов API нет, исходные объявления и датасеты не используются.
Все входы и оболочки ответов определены в `run.py`, чей отпечаток включён
в `code_sha256` отчёта.

Проверяем формат запросов, авторизацию, передачу таймаута, раздельные настройки
шагов, явный выбор провайдера и режимов JSON, отсутствие API-вызова без ключа.
Проверяем HTTP 200 HTML, неверный JSON, NaN/Infinity, объект `error`, пустые,
оборванные и заблокированные генерации, thinking, отказ и tool calls.
Проверяем ограничение повторов, исчерпание попыток, Retry-After в секундах
и HTTP-date, отсутствие повторов постоянных ошибок и запрет redirect с ключом.

Критерий успешности — выполнение всех проверок контракта. Сценарий не измеряет
micro-F1, качество текста, фактическую достоверность, скорость или стоимость
модели. Системного промпта решения здесь нет; таблица сравнения промптов
не применяется.

## Запуск

```bash
uv run python src/draft_generation/benchmarks/api_clients/run.py --all-revisions
```

Запуск только текущей рабочей копии:

```bash
uv run python src/draft_generation/benchmarks/api_clients/run.py
```

Запуск на конкретной версии общих клиентов:

```bash
uv run python src/draft_generation/benchmarks/api_clients/run.py --revision HEAD --report /tmp/api-clients-head.json
```

`--all-revisions` проверяет рабочую копию, текущий HEAD и все коммиты из
`git log -- src/main.py`, то есть версии общего кода клиентов в текущей истории.
Если клиент отсутствует, версия помечается `unavailable` с перечнем недостающих
символов. Чужие результаты не подставляются, такой статус не считается
успешным выполнением проверок этой версии. При наличии клиентов выполняется
тот же сценарий на коде `main.py` выбранного коммита.

Актуальный отчёт — [results.json](results.json). `--report` меняет путь.
Время `offline_elapsed_seconds` включает загрузку проверяемого модуля и
выполнение проверок с подменёнными сетью и ожиданиями; это **не время ответа
модели**. Проверки постоянных/временных HTTP-ошибок не отправляют запросов.
