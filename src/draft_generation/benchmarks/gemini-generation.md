# Бенчмарк: генерация Google Gemini с существующим ключом

Сервис: draft_generation
Дата: 2026-11-14   Автор: ARCshekin

## Что проверяем и почему

Реальная авторизация, схема ответа и интеграция генератора в полный CLI.
Используется существующий `LLM_API_KEY`, ключ не записывается в отчёт.
Google ListModels подтвердил доступ к генеративным моделям.
`gemini-2.5-flash-lite` при реальном вызове вернула 404 с рекомендацией
перейти на `gemini-3.5-flash-lite`; выбрана последняя.
Модель классификатора `LLM_MODEL_ID=gemini-decision-1` не меняется.

Вход реального main.py (`data/input.json`):

```json
{
  "description": "Делаем ремонт квартир под ключ, а также отдельно выполняем сантехнические работы: разводку труб, установку раковин и унитазов, замену смесителей и подключение стиральных машин. Помогаем подобрать материалы и согласовываем стоимость до начала работ.",
  "mcId": 101
}
```

Запуск:

```bash
uv run python src/main.py --input data/input.json --output out/main-live-output.json
PYTHONPATH=src uv run python -m draft_generation.benchmarks.replay_sample_llm
```

## Выводы

Генерация подтверждена реальным ответом с существующим Google-ключом.
Pydantic-схема передаётся в API и дополнительно проверяется локально.
Повторы ограничены и применяются только к временным HTTP-ошибкам и таймаутам.
Качество текста требует отдельной экспертной оценки.
Секреты и существующий `.env` не менялись.
