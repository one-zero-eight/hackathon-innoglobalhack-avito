## Что проверяем

64 офлайн-проверки для Google и OpenAI-compatible через настоящий loader,
генератор, оркестрацию и CLI. Подменяются только ответы API. Проверяем
уникальность и порядок целей, проверку всего списка до вызова API, пустой
источник, все исходные категории, строгую схему, приватность ошибок,
сохранение исходного JSON, отказ на ошибку второй цели, пустой ответ
классификатора и сохранность прежнего выходного файла при ошибке генерации.

Факты и текст модели не оцениваются: ответы подменены. Системный промпт
передаётся генератору, но лучший промпт здесь не выбирается. Нельзя считать
эти результаты подтверждением отсутствия галлюцинаций или успешного live API.
Данные и ответы контрольных случаев находятся в run.py; отчёт содержит их имена.
