# Бенчмарк: HTTP-контракт FastAPI

Сервис: draft_generation; проверяется HTTP-адаптер общего пайплайна.

## Что проверяем

JSON входа и выхода, mcId aliases, пустой результат, 422 до вызова моделей,
health, Swagger/OpenAPI, 405 для неверного метода, 502 для ошибок модели и
её JSON, исполнение синхронного пайплайна в worker thread, отказ при
неполной конфигурации. Контрольные входы заданы в run.py, ответы run_pipeline
подменены. Это не измерение качества или задержки LLM.

## Запуск

```bash
uv sync
uv run python src/draft_generation/benchmarks/http_api/run.py
```

Используются FastAPI TestClient и HTTPX2 из dev-зависимостей, без pytest.
В ограниченном sandbox доступ к локальным сокетам event loop может быть
запрещён; проверка выполнена вне этого ограничения. Реальных моделей она
не вызывает. Отчёт: [results.json](results.json).

## Выводы

HTTP-контракт подтверждён. Дополнительно реальный Uvicorn на localhost:8000
проверен через HTTP: health 200, OpenAPI 200, пустое описание даёт drafts=[]
с HTTP 200, неверный mcId — 422. При этом вызовов моделей не было.
Непустые запросы используют настоящие настроенные API; доступность Gemma
отдельна от доступности HTTP-сервера. Прежняя генерация Google давала 500,
и адаптер передаст её как 502, без фиктивного успешного ответа.
