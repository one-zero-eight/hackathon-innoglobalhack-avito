# Бенчмарк: расчёт метрики полного решения

Сервис: draft_generation (оценка категорий из итоговых drafts обоих шагов)
Дата: 2026-11-13   Автор: ARCshekin

## Что проверяем и почему

Проверяем новый `src/run.py`, а не качество конкретного классификатора.
Источник правил: `docs/innoglobalhack_avito/hackathon-evaluation.md`.
Метрика — sklearn micro-F1 на бинарных матрицах со всеми шестью категориями.
Баллы за классификацию — 60 × micro-F1. Полностью пустой эталон и ответ
дают 0 (`zero_division=0`); повторы mcId не увеличивают TP.

Вход контрольного примера:

```json
{
  "input": {"description": "Контрольный пример", "mcId": 101},
  "expected": [102, 105],
  "output": {
    "drafts": [
      {"mcId": 102, "title": "Контроль", "text": "Контрольный пример"},
      {"mcId": 104, "title": "Контроль", "text": "Контрольный пример"}
    ]
  }
}
```

### Воспроизводимая проверка формулы и чтения официального датасета

```bash
PYTHONPATH=src uv run python - <<'PY'
from pathlib import Path
from run import calculate_metrics, read_records, prepare_rows, audit_overlap

m = calculate_metrics([{102, 105}], [{102, 104}])
assert m == {
    "micro_f1": 0.5, "classification_points": 30.0,
    "tp": 1, "fp": 1, "fn": 1,
}
assert calculate_metrics([set()], [set()])["micro_f1"] == 0
assert calculate_metrics([{102}], [{101, 102}])["fp"] == 1
assert calculate_metrics([{102}], [{102}])["micro_f1"] == 1
assert calculate_metrics([{102}, set()], [{102}, {104, 105}])["micro_f1"] == 0.5
root = Path("docs/innoglobalhack_avito")
rows = prepare_rows(read_records(root / "public-test-dataset.parquet"), 101)
assert len(rows) == 208
assert set.union(*(row.expected for row in rows)) == {102, 103, 104, 105, 106}
overlap = audit_overlap(rows, root / "public-train-annotated.jsonl")
assert overlap["overlapping_rows"] == 24
PY
```

Полный запуск после выбора обоих реализованных модулей:

```bash
uv run python src/run.py --config run.config.json
```

полноценное сравнение всех версий остаётся обязательным перед коммитом.

## Выводы

Расчёт соответствует критериям (60 × micro-F1, а не исторические 5 × F1).
Ошибка обработки не превращается в пустое предсказание.
Для измерения качества нужно выбрать модули извлечения и генерации
в `config.json` и настроить API. Позднее в этой же ветке по запросу
пользователя добавлен и выбран `draft_generation/sample_llm`;
его отдельный офлайн-бенчмарк — в `src/draft_generation/benchmarks/`.
Публичный контракт и существующие реализации сервисов не изменены.
Пересечение с train предупреждает о потенциальной утечке, но не проверяет
все близкие варианты описаний и не доказывает отсутствие утечки.
