# Бенчмарк: время генерации одного черновика
Сервис: draft_generation

## Что проверяем

Настоящий `sample_llm.run()` с одной целевой категорией на10 непустых
validation-входах официального train, seed44.
SHA-256: `b7118d68086624fbeab43839f22a635d4e325e4ee339f22d4aa0ad3c2e986615`.
Загрузка не входит в latency; ожидание квоты и повторы входят.
Смысловая достоверность текста не оценивается.

## Запуск

Без API, только фиксация отсутствия свежего замера:

```bash
uv run python src/draft_generation/benchmarks/response_time/run.py --offline
```

Выход: [results.json](results.json), код1 означает недоступный замер.
Для настоящих вызовов уберите `--offline`; нужен рабочий Google API-ключ.
