# Время ответа генератора

Сервис: draft_generation.

## Что проверяем

10 настоящих запросов к `gemini-3.5-flash-lite`. На каждом входе — один черновик
для минимального эталонного mcId. Входы выбираются без повторения из непустых
validation-групп официального train: то же разбиение, что
[TF-IDF](../../../subcategory_extraction/benchmarks/tfidf_quality/README.md), seed выборки 44.
Классификатор не вызывается. Цели из эталона нужны только для выбора
категории черновика, в промпт передаются категория и исходное описание.

Таймер оборачивает настоящий `run()` и проверку выходного контракта;
загрузка экземпляра и чтение выборки не входят. Прогрева нет.
При повторах их ожидания включаются. В данном прогоне 10/10 ответов
содержат ровно один валидный черновик нужной категории.

## Запуск

```bash
uv run python src/draft_generation/benchmarks/response_time/run.py
```

`--size` меняет число входов; `--report` — путь отчёта.
Нужен `LLM_API_KEY` в `.env`. [Полный отчёт](results.json) содержит реальные
черновики и время каждого запроса; повторный запуск не использует кэш.
