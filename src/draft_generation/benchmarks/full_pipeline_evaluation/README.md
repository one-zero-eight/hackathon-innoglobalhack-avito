# Бенчмарк: полный пайплайн и общий оценщик

Офлайн проверяем формулу micro-F1, крайние случаи, чтение public-test
и аудит пересечений с train. Live оценивает категории итоговых drafts,
а не смысловую достоверность их текстов. SHA-256 test:
`65b5a45a98b577d853a928932bbbdf8bd9bdeb469ded3016faace4d11f3eabaa`.

## Запуск

```bash
uv run python src/draft_generation/benchmarks/full_pipeline_evaluation/run.py
```

Офлайн-отчёт — [checks-results.json](checks-results.json).
Настоящая полная цепочка: --live --config <run-config.json>,
для продолжения — --resume. Live-отчёт — [live-results.json](live-results.json).
API-вызовы могут быть платными. При переоформлении новые вызовы не делались.

Повторный запуск заменяет строку соответствующего решения/конфигурации,
остальные строки сохраняются с исходными датами. Не добавляем таблицы
«новый прогон», «история» или «промпты». Замер live относится к указанной
TF-IDF-цепочке, а не к текущему выбранному semantic_encoder_f1.
24 пересечения test/train ограничивают независимость этой оценки.
