и аудит пересечений с train. Live оценивает категории итоговых drafts,
а не смысловую достоверность их текстов. SHA-256 test:

## Запуск

```bash
uv run python src/draft_generation/benchmarks/full_pipeline_evaluation/run.py
```

Офлайн-отчёт — [checks-results.json](checks-results.json): results.evaluator сохраняет прежние проверки, results.http_api — API/runtime.

Проверки API без PostgreSQL, весов внешних моделей и облачных запросов:

```bash
uv run python src/draft_generation/benchmarks/full_pipeline_evaluation/run.py --api-check
```

Этот режим проверяет обнаруженные extractor/generator-модули в Swagger, defaults/overrides,
reuse обоих шагов, конкурентные запросы, отказ от неподтверждённых услуг без фиктивных drafts,
безопасные 422/502/503, веб-контракт, CLI и запуск python -m src из другого cwd.
Платный транспорт заблокирован; ответы генерации контрольные. Сохраняются происхождение
и даты остальных строк. Реальный временный HTTP-сервер останавливается после проверки.
Настоящая полная цепочка: --live --config <run-config.json>,
для продолжения — --resume. Live-отчёт — [live-results.json](live-results.json).
HTTP smoke использует настоящие regex и локальную Qwen3.5-9B, без подмены ответов.
Это функциональный пример, не F1 и не сравнение моделей; исходник и полный ответ
сохранены в `checks-results.json`, `results.local_http_smoke`.
Веб-сервис подключён к настоящему PostgreSQL; health и шесть микрокатегорий
проверены. Полная веб-классификация Jev не проверена: `SELECTEL_API_KEY` отсутствует.
Live API-вызовы могут быть платными. Исторические оценки F1 в этом прогоне не пересчитывались.

Повторный запуск заменяет строку соответствующего решения/конфигурации,
остальные строки сохраняются с исходными датами. Не добавляем таблицы
«новый прогон», «история» или «промпты». Замер live относится к указанной
TF-IDF-цепочке, а не к текущему выбранному semantic_encoder_f1.
24 пересечения test/train ограничивают независимость этой оценки.
