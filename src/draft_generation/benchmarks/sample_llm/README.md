# Бенчмарк: офлайн-контракт генератора
Сервис: draft_generation

## Что проверяем

Штатный `sample_llm`: JSON-схему, категории, дубликаты целей, пустые цели,
ошибки транспорта и повторы, полную цепочку через `run_pipeline`.
Ответы транспорта подменены контрольными фикстурами, настоящая LLM не вызывается.
Это проверка контракта, не оценка качества или достоверности текста.

```json
{"description":"Устанавливаю розетки и смесители.","mcId":101}
```

Цели:104/105; JSON-фикстура ответа:
`{"title":"Монтаж","text":"Установка смесителей."}`.

## Запуск

```bash
uv run python src/draft_generation/benchmarks/sample_llm/run.py
```

Выход: [results.json](results.json). Внешних запросов и расходов нет.
