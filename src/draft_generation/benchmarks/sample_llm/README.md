# Контракт генератора sample_llm

Сервис: draft_generation.

## Что проверяем

Офлайн-проверка передачи категории и описания, схемы ответа, уникальности
целей, пустого входа, ошибок HTTP и повторов, а также интеграции двух модулей.
Транспорт и ответы подменены; настоящих обращений к модели нет.

## Запуск

```bash
uv run python src/draft_generation/benchmarks/sample_llm/run.py
```

[Отчёт](results.json) перезаписывается фактическим результатом запуска.
