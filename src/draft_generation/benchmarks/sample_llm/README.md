# Бенчмарк: офлайн-контракт генератора

Штатный sample_llm: JSON-схема, категории, повторяющиеся и пустые цели,
ошибки транспорта, повторы и цепочка через run_pipeline. Ответы транспорта
подменены контрольными фикстурами; настоящая LLM не вызывается.
Это проверка контракта, а не качества текста или галлюцинаций.

Вход: `{"description":"Устанавливаю розетки и смесители.","mcId":101}`.
Цели: 104/105. Ответ-фикстура:
`{"title":"Монтаж","text":"Установка смесителей."}`.

## Запуск

```bash
uv run python src/draft_generation/benchmarks/sample_llm/run.py
```

Отчёт — [results.json](results.json). Повторная проверка заменяет строку
этой конфигурации; отдельные таблицы прогонов и промптов не создаём.
Проверки других конфигураций должны сохранять свои строки и происхождение.
Исходный снимок — [recorded-results.json](recorded-results.json).
Переоформление не является новым выполнением проверок или вызовом модели.
