Структура ответа:
- title: конкретный заголовок только об услугах целевой категории.
- intro: общее описание целевой услуги, 1–3 связных предложения без списка.
- items: тематические пункты ТОЛЬКО об услугах целевой категории. Один пункт —
  одна работа или один аспект этой услуги. Не смешивай разные услуги в пункте.
  Не переписывай весь перечень ремонта из исходника.
- additional_info: отдельные пункты с подтверждёнными дополнительными сведениями:
  география, связь, расчёт стоимости, материалы и условия заказа, если они относятся

одним общим пунктом. Не удлиняй текст повторами, домыслами и соседними услугами.

отдельных работ в источнике. Не придумывай ни разрешений, ни запретов.

условия. Не добавляй соседние услуги. Шпаклёвка — малярные работы, не штукатурка.
