# Бенчмарк: выбор дополнительных микрокатегорий с Gemini

Сервис: subcategory_extraction  
Дата: 2026-11-13  
Автор: fih

## Что проверяем и почему

Сравниваем краткую инструкцию и инструкцию с границами категорий на 32
объявлениях из `public-train-annotated.jsonl`. Выборка воспроизводится через
`random.Random(42).sample` по строкам файла в исходном порядке. Исходная
категория у всех объявлений — 101, эталон — `found_microcategories`. В выборке
114 положительных меток и четыре объявления без дополнительных категорий.
Разметка автоматическая, поэтому оценка показывает согласие с публичными метками.

Gemini получает только `description` и `mcId` для каждого объявления.
Оба промпта получают одни и те же группы по четыре объявлений в том же порядке.
Эталон и предсказание кодируются бинарными матрицами с колонками 101–106.
Дубликаты считаются один раз. Возврат исходной категории считается FP.
Метрика — `sklearn.metrics.f1_score(average="micro")`, баллы — 5 × micro-F1.

## Входные данные

Пример из выборки (`item_id=2510066500119`, эталон `[104]`).

```json
{
  "description": "Ремонт квартир.\nСан.узлы под ключ.\nЗамена сантехники.\nВнутренняя и наружная отделка любых помещений.\nКровля, фасады.",
  "mcId": 101
}
```

## Выводы

Краткий промпт набрал на 0.0092 micro-F1 больше. Оба промпта дали по шесть
ложных срабатываний, а промпт с правилами пропустил на две метки больше.
Для выбора промпта нужна проверка на отдельном размеченном наборе.

Из шести ложных срабатываний промпта с правилами пять — исходная категория
101. Если применить предусмотренную пайплайном фильтрацию исходной категории
к тем же ответам, краткий промпт сохраняет micro-F1 0.9565, а промпт с
правилами получает 0.9686 (108 TP, 1 FP, 6 FN). Основная таблица показывает
оценку ответов Gemini до этой фильтрации.
