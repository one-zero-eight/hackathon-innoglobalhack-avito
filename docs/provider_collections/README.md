| Файл | Строк | Источник и назначение |
| --- | ---: | --- |
| [Youla с разметкой](youla-859-annotated.jsonl) | 859 | `out/youla-800-plus-plastering-labels.jsonl`. Обучение в бенчмарке переноса на InnoGlobalHack |

| [Яндекс Исполнители, исходные профили](yandex-1492-raw.jsonl) | 1 492 | `out/yandex/profiles-1492.jsonl`. Корпус для отдельного эксперимента |

В двух полных снимках Decision 1 каждая строка содержит исходную запись
`source`, настройки разметки `configuration`, оценки `probabilities`
и список `found_microcategories` при пороге 0.50. У заблокированной строки
Youla оценки и список равны `null`. Снимки сохраняют метку 101, а бенчмарк
переноса оценивает категории 102–106.


Youla содержит `platform`, `url`, `sample_mc_id`, `title`, `description`
и `source_type`. `sample_mc_id` отражает предварительное соответствие
рубрики источника. В размеченном файле также есть `probabilities`,
`target_mc_ids` и `input_tokens`. Gemini Decision 1 оценивал категории
102–106 с исходной категорией 101. Метки получены при пороге 0.50.

Первые 800 строк размеченного файла совпадают с исходной обучающей выборкой
из 800 строк. Последующие 59 получены при целевом отборе штукатурных работ
после исключения одного совпадения с InnoGlobalHack. Все 859 размеченных
объявлений присутствуют в исходном снимке Youla с теми же URL и описаниями.

Файл Яндекса содержит `platform`, `provider_id`, `catalog_url` и
`description`. Рубрика в `catalog_url` указывает источник сбора.
Оба исходных снимка содержат данные без целевых меток. Для оценки качества
используются отдельные выборки из официального train InnoGlobalHack.

SHA-256 можно проверить командой `shasum -a 256 -c SHA256SUMS` из этой папки.

## Перенос в актуальную структуру

Снимки перенесены без изменения байтов из PR #9,
commit `283b2e046ea806aea745fb125669c6e6a904fb22` (2026-11-14).
Это внешние предварительно размеченные коллекции, а не test-наборы
четырёх актуальных бенчмарков. Обучение опубликованного `learned_keywords`
на них не проводилось. Согласно AGENTS.md обучение и подбор параметров
в текущем решении используют только train InnoGlobalHack.
Исторические эксперименты переноса с Юлы доступны в истории PR;
их метрики не являются оценкой новых весов.

Сборщики: `src/collection/{youla,yandex}/`.
Разметка: `src/dataset_annotation/{collection_decision,youla_gemma}/`.
