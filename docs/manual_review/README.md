# Новая смысловая разметка InnoGlobalHack

**Работа не завершена. Это журнал индивидуального чтения, а не готовый датасет.**
Исходные метки и результаты прежнего автоматического аннотатора не используются
как подсказки. Действующие файлы improved_dataset пока не перезаписываются.

По указанию пользователя первая партия 500 (батчи 001–005) считается
завершённой: пересмотр старых решений под новые политики не выполняется,
работа продолжается с 501-й записи. Все 11 вопросов к пользователю разрешены
в чате 2026-11-14 (ответы зафиксированы в policy.json, revision 11).
Автоматической замены недостающей смысловой разметки не выполнялось.

Источник — оригинальные 10 000 train и 208 test-строк. После глобальной
дедупликации осталось 4980 описаний. Для ключа дубликата применены NFKC,
casefold, ё→е и схлопывание пробелов; сам description сохранён без изменений.
Близкие, но не совпадающие тексты автоматически не удаляются.
Повтор одного текста в train и test читается один раз, все исходные ссылки
сохраняются. Это не означает разрешения смешивать train и test при обучении:
исключение пересечений нужно будет выполнить при сборке итоговых частей.

## Работа

- `inputs.jsonl` — описания и ссылки на исходные записи, без старых меток и title.
- `batches/NNN.jsonl` — задания по 100 описаний, по пять заданий на пакет 500.
- `reviews/NNN.jsonl` — индивидуальные решения агентов после чтения текста.
- `policy.json` — текущие принципы и прямые уточнения пользователя.
- `manifest.json` — происхождение, SHA-256 и техническая дедупликация.
- `progress.json` и `questions.jsonl` — техническая сводка внесённых решений
  и неразрешённые вопросы с полными исходными описаниями.

Одновременно доступно три субагента: общий лимит с главным агентом — четыре.
Пять заданий по 100 выполняются двумя волнами. Каждое объявление читается
целиком, включая контекст и границы SEO. Использование regex, словарного
классификатора или модельных предсказаний для назначения меток запрещено.
Скрипт только готовит файлы и проверяет технические инварианты.

При сомнении агент ставит `status=needs_user`, `labels=null` и формулирует
вопрос. `[]` используется для уверенного пустого набора, не для сомнения.
После ответа пользователя затронутые записи перечитываются и исправляются
по смыслу; массовая автоматическая переклассификация не применяется.

```bash
uv run python src/dataset_annotation/manual_review.py prepare
uv run python src/dataset_annotation/manual_review.py validate
```

Валидация проверяет ID, назначенный пакет, уникальность, формат статусов,
точность цитат и полноту учёта. Она **не доказывает смысловую правильность**
или фактическое полное прочтение: за разбор отвечает агент, главный агент
проверяет основания и передаёт сомнения пользователю.

До завершения всех 4980 записей и разрешения вопросов не заявляем полную
переразметку, не обучаем на этом журнале модели и не подменяем им эталон F1.
